# Madhav Ecommerce Sales Dashboard 📊

## Overview
This repository contains an interactive **Power BI dashboard** built on ecommerce sales data (CSV file).  
The dashboard provides a comprehensive view of **sales, profit, average order value (AOV), and quantity**, segmented by category, payment mode, customer, and geography.  
It is designed to highlight business insights and support decision-making.

## Features
- 📈 **Profit by Month** – Seasonal trends with positive and negative months
- 🛒 **Category Analysis** – Furniture, Electronics, Clothing
- 💳 **Payment Mode Insights** – COD, UPI, Credit/Debit, EMI
- 👤 **Customer & State-wise Sales** – Distribution across key regions
- 🔑 **KPIs** – Total Amount, Quantity, Profit, AOV

## Tools & Skills Used
- **Power BI** – Dashboard creation, DAX measures, interactive visuals  
- **Excel** – Data cleaning and preprocessing  
- **SQL** – Querying and data transformation  

## Key Insights
- Clothing contributes **63% of total quantity** sold.  
- COD is the most popular payment mode (**44% share**).  
- Profit dips in **May, June, and August**, suggesting seasonal challenges.  

## Repository Contents
- `Madhav_Ecommerce.pbix` → Power BI dashboard file  
- `Dataset.csv` → Raw dataset used for analysis  
- `Dashboard_Screenshot.png` → Visual preview of the dashboard  

## How to Use
1. Download the `.pbix` file and open it in **Power BI Desktop**.  
2. Explore interactive filters (Quarter, State) to view customized insights.  
3. Review the dataset (`.csv`) for preprocessing and validation.

# 🛍️ Madhav E-Commerce Sales Dashboard

## 📌 Overview
This project is an end-to-end **Power BI analysis** of Madhav E-Commerce sales data.  
The goal is to uncover **sales trends, product performance, and customer behavior** to drive **data-informed business decisions**.

## 🧰 Tools & Technologies
- **Power BI** – Dashboard creation and data visualization  
- **Excel** – Initial data cleaning and formatting  
- **SQL** – Data transformation and querying  

## 📂 Data Source
Sample e-commerce dataset containing:
- Transaction records  
- Product details  
- Customer information  

> **Note:** No sensitive or personal data is shared.

## ✨ Key Features / Analysis Performed
- Cleaned and transformed raw data using **SQL & Excel**  
- Built **interactive Power BI dashboards** with slicers and filters  
- Visualized **monthly profit**, **category-wise quantity**, and **customer-wise sales**  
- Analyzed **payment modes** and **sub-category profitability**  
- Delivered insights for **inventory planning** and **marketing strategy**
