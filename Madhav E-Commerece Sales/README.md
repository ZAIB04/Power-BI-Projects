# Madhav Ecommerce Sales Dashboard 📊

## Overview
This repository contains an interactive **Power BI dashboard** built on ecommerce sales data (CSV file).  
The dashboard provides a comprehensive view of **sales, profit, average order value (AOV), and quantity**, segmented by category, payment mode, customer, and geography.  
✨ *Interactive dashboard delivering actionable ecommerce insights for business growth.*

## Features
- 📈 **Profit by Month** – Seasonal trends with positive and negative months  
- 🛒 **Category Analysis** – Furniture, Electronics, Clothing  
- 💳 **Payment Mode Insights** – COD, UPI, Credit/Debit, EMI  
- 👤 **Customer & State-wise Sales** – Distribution across key regions  
- 🔑 **KPIs** – Total Amount, Quantity, Profit, AOV  

---

## Tools & Skills Used
- **Power BI** – Dashboard creation, DAX measures, interactive visuals  
- **Excel** – Data cleaning and preprocessing  
- **SQL** – Querying and data transformation  

---

## Key Insights
- Clothing contributes **63% of total quantity** sold.  
- COD is the most popular payment mode (**44% share**).  
- Profit dips in **May, June, and August**, highlighting seasonal challenges.  
- Maharashtra and Uttar Pradesh show strong sales performance compared to other states.

## How to Use
1. Download the `.pbix` file and open it in **Power BI Desktop**.  
2. Explore interactive filters (Quarter, State) to view customized insights.  
3. Review the dataset (`.csv`) for preprocessing and validation.  
4. Use the screenshot for a quick preview of dashboard visuals.
