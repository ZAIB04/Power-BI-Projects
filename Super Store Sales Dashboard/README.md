# 📊 Super Store Sales Dashboard (Power BI)

## 📌 Overview
This project is an interactive **Power BI dashboard** built using the Super Store dataset.  
It provides insights into sales performance, profit trends, customer behavior, and regional analysis to support data-driven decision-making.

---

## 🎯 Objectives
- Analyze overall sales and profit performance  
- Identify top-performing categories and sub-categories  
- Track monthly sales and profit trends (Year-over-Year)  
- Understand customer segments and shipping preferences  
- Visualize regional sales distribution  

---

## 📈 Key Insights
- 💰 Total Sales: **522K**  
- 📊 Total Profit: **68K**  
- 📦 Total Quantity Sold: **7298**  
- 🚚 Average Delivery Time: **9 Days**  

---

## 📊 Dashboard Features

### 🔹 Sales Analysis
- Sales breakdown by **Category & Sub-Category**
- Monthly **Sales Trends (YoY)** comparison  
- Sales distribution by **Region**

### 🔹 Profit Analysis
- Monthly **Profit Trends (YoY)**  
- Profit contribution by different categories  

### 🔹 Customer Insights
- Sales by **Segment (Consumer, Corporate, Home Office)**  
- Sales by **Payment Mode (COD, Online, Cards)**  

### 🔹 Shipping Analysis
- Sales by **Ship Mode (Standard, Second Class, First Class, Same Day)**  

### 🔹 Geographic Analysis
- Interactive **Map Visualization** showing sales by state  

---

## 🛠 Tools & Technologies
- Power BI  
- Microsoft Excel / CSV Dataset  
- Data Cleaning & Transformation (Power Query)

## 📂 Dataset

  - Shipping Data

## 🚀 How to Use
1. Download the `.pbix` file from this repository  
2. Open it in **Power BI Desktop**  
3. Explore the dashboard using filters and slicers
